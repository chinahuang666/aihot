# 抓取层安全（SECURITY）

`pipeline/httpclient.py` 的 `SafeSession` 实现任务书 §12 的安全要求。

## SSRF 防护
- 仅允许 `http/https`。
- 解析主机名后，对每次解析到的 IP 校验，拒绝命中以下网段的地址：
  回环 `127.0.0.0/8`、私有 `10/8` `172.16/12` `192.168/16`、链路本地/云元数据
  `169.254.0.0/16`（含 `169.254.169.254`）、IPv6 回环/唯一本地/链路本地。
- 重定向后再次校验最终跳板地址（防止重定向绕过）。

## 鲁棒性与资源限制
- 连接/读取超时（默认 20s）。
- 自有指数退避重试（默认 2 次）。
- 响应体体积上限（`MAX_BODY_BYTES = 5MB`），流式读取，超限即截断。
- MIME 白名单（XML/RSS/Atom/JSON/HTML 等），拒绝非预期类型。
- 条件请求：`ETag` / `Last-Modified`（304 复用）+ 简单磁盘缓存。

## 数据最小化与隐私
- 全程不收集任何用户数据；无运行时后端、无数据库。
- LLM（可选）仅在显式配置密钥与预算后调用，且任何失败回退规则摘要，不外发原文到第三方。

## 供应方可靠性
- GitHub 发布源使用公开 Atom Feed，避免 API 限额与鉴权凭证暴露。
- 单来源失败不影响整体；健康检查对外可见（`source-status.json`）。
